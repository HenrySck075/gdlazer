SESSION SUMMARY - Flutter Widget/Element System Port to C++
============================================================

[related files are under include/gdlazer/caffeine and src/caffeine, this particular subproject is called caffeine obviously]


OBJECTIVE:
Implement foundational widget classes (StatelessWidget, StatefulWidget, RenderObjectWidget, ProxyWidget) and their corresponding elements for a Flutter-inspired C++ framework targeting cocos2d-x 2.2.3 in Geometry Dash.

KEY DECISIONS & ARCHITECTURE:
- Ported Flutter's complete widget/element tree system from Dart to C++
- API Design: Developers return raw Widget* from build() methods; framework wraps in shared_ptr internally
- Removed shared_ptr_ctor utility in favor of raw pointers in public APIs
- Element inherits from std::enable_shared_from_this<Element> for safe shared_ptr conversion in member functions
- Build returns Widget* (not shared_ptr) to simplify developer experience
- State lifecycle: initState(), didUpdateWidget(), dispose() + setState(lambda) for triggering rebuilds

CLASSES IMPLEMENTED:
1. StatelessWidget → StatelessElement (single build) ✓
2. StatefulWidget + State → StatefulElement (stateful lifecycle) ✓
3. RenderObjectWidget (abstract, renders CCNode) ✓
4. SingleChildRenderObjectWidget → SingleChildRenderObjectElement ✓
5. MultiChildRenderObjectWidget → MultiChildRenderObjectElement ✓ (with basic child reconciliation)
6. ProxyWidget → ProxyElement (delegates to child widget) ✓
